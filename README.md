# FluxMotion — GitHub Pages

이 폴더의 **내용 전체**를 `fluxmotion1/fluxmotion1.github.io` 저장소 루트에 업로드하세요. `index.html`이 저장소 최상위에 있어야 합니다. `.nojekyll`도 포함하세요.

저장소 Settings → Pages → Build and deployment에서 Deploy from a branch, main, /(root)를 선택합니다. 계정/조직 이름이 fluxmotion1인 경우 주소는 https://fluxmotion1.github.io/ 입니다.

별도의 설치·빌드·서버·API 키가 필요 없습니다. 9개 페이지, CSS, JavaScript, 모든 이미지와 로컬 글꼴이 포함되어 있습니다. 링크는 루트 서비스용 `/assets/`, `/robotics/` 등의 경로를 사용합니다. 저장소 하위 경로 서비스용이 아닙니다.

로컬 확인: 이 폴더에서 `python -m http.server 8080` 실행 후 http://localhost:8080/ 접속. 파일을 더블클릭하는 file:// 방식은 루트 경로 링크를 지원하지 않습니다.

원본과의 차이:
- Google Fonts 원격 로딩을 로컬 글꼴로 대체했습니다. 글꼴 라이선스는 assets/fonts/*-OFL.txt에 포함됩니다.
- 문의는 원본과 동일한 mailto 링크이며 사용자 메일 앱을 엽니다. 서버에서 메일을 자동 발송하는 기능은 없습니다.
- 오시는 길의 지도 링크는 클릭 시 외부 Google Maps로 이동합니다.
- 한영 선택은 브라우저 localStorage에 저장됩니다. 도메인이 달라지므로 원본 도메인의 언어 선택은 이전되지 않습니다.
- ChatGPT Sites 편집·배포 기능은 포함되지 않습니다. 이후 수정은 GitHub 저장소에서 진행합니다.
- GitHub Pages가 제공하는 HTTPS를 사용합니다. 기존 ChatGPT 주소는 자동 변경·리디렉션되지 않습니다.
